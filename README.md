# ШУМГЕР — Сайт компании по монтажу площадок

Многостраничный статический сайт для компании ШУМГЕР, специализирующейся на монтаже детских площадок, воркаут-зон и МАФ.

## Дизайн

**Стиль:** Military Khaki — тёмная тема с хаки-акцентами
- Основной цвет: `#c8d96f` (лаймово-хаки)
- Фон: `#2a2e1e` (тёмный хаки)
- Карточки: `#333829`
- Текст: `#f4f2e6` (кремовый)
- Шрифт: Space Grotesk

## Структура

```
shumger-site/
```

## Страницы

1. **Главная** — герой с крупным заголовком, преимущества, услуги, CTA
2. **Услуги** — детальное описание 4 направлений (детские площадки, воркаут, МАФ, покрытия)
3. **Портфолио** — сетка реализованных проектов (6 примеров)
4. **О компании** — текст о компании, статистика, преимущества
5. **Калькулятор** — форма для расчёта стоимости
6. **Контакты** — контактная информация + форма обратной связи
7. **Политика конфиденциальности** — юридический текст
8. **404** — страница ошибки

## Особенности

- Адаптивная вёрстка
- Тёмная тема с хаки-акцентами
- Анимация карточек при скролле
- Формы с валидацией и маской телефона
- Sticky-навигация
- Инженерная сетка на фоне героя

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
# или
npx serve
```

Затем откройте http://localhost:8000

## Контакты в формах

Сейчас формы отправляют данные через `mailto:info@shumger.ru`.
Для продакшена рекомендуется настроить:
- Backend для обработки форм
- Или интеграцию с сервисом (FormSpree, Netlify Forms, Google Forms)

## Доработки

Для полноценного запуска нужно:
1. Добавить реальные фотографии проектов в портфолио
2. Заменить контактные данные (телефон, email, адрес)
3. Настроить обработку форм на сервере
4. Добавить favicon
5. Настроить SEO (meta-теги, Open Graph)
